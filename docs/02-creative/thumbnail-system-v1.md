# Thumbnail system v1

## Objective

Create recognizable, high-clarity thumbnails that sell a scenario at feed size without abandoning the Midnight Everyman visual language. The thumbnail presents one intriguing relationship; the episode explains it.

## Research correction

The initial 2026-08-17 reference scan emphasized lifetime view leaders. That sample disproportionately surfaced legacy YouTube packaging: red arrows, alarm words, exaggerated reaction faces and explicit danger cues. It was useful history but a poor basis for a current house style.

A second scan restricted to recent 2026 breakout explainers. The more useful current patterns were:

- A single visually impossible or surprising image with little or no text
- A controlled before/after or cause/effect comparison with neutral labels
- An editorial illustration in which the human figure belongs to the scene rather than reacting beside it
- For list and compression episodes, a clean inventory or icon grid
- Strong silhouette, scale contrast and color separation without clickbait annotation
- Title and thumbnail sharing the promise without repeating the same words

Reference performance does not prove that a layout caused the views; channel size, topic, timing and distribution remain confounders. Treat this scan as current compositional evidence and let native YouTube tests decide.

## House rules

- Canvas: 1280 x 720, 16:9.
- Design for phone-feed size before inspecting at full resolution.
- Show one scenario or relationship, not a summary of the episode.
- Use one dominant visual idea occupying approximately half the frame.
- Limit supporting elements to what makes the relationship legible.
- Use the house teal, coral, mustard, ink and paper palette, with stronger contrast than the in-video stage.
- Keep texture broad and restrained; fine paper grain disappears at feed size.
- Use simplified shapes and confident outlines consistent with the UPA-derived house language.
- Prefer zero text. When text is necessary, use one or two functional labels rather than a slogan.
- If Everyman appears, integrate him into the event. Do not paste a reaction face beside an unrelated object.
- The image must remain intelligible in grayscale and at approximately 160 pixels wide.

## Attention hierarchy

*Restored 2 Sep 2026. This was documented on a retired design sheet and did not
survive the move into this file.*

A thumbnail has a **main character** — the one thing the eye must land on first —
and **supporting characters** that make the curiosity gap legible a beat later.
Diagnose any composition by asking where the eye goes first, second and third,
and whether that order is the one you intended.

Attention is directed by four things, in roughly this order of force:

1. **Brightness** — the brightest element wins, whatever it is.
2. **Position** — upper-left is read first, because that is how the eye scans.
3. **Size**.
4. **Proximity** — whatever appears closest to the camera reads as nearest.

**The standard failure:** large, high-contrast type placed top-left becomes the
main character by default, and the object becomes supporting. If the object is
meant to lead, the text goes lower, quieter, and third in the order — or the
object goes brighter and larger. This is not a stylistic preference; it is the
mechanism by which the frame is read.

## The three-element ceiling

*Also restored 2 Sep 2026.*

Three main things on the canvas, maximum. Count them honestly: an object, a
figure, a label and two text blocks is five, not three, and five is more than a
feed viewer will parse.

For this channel the usual three are **object, intruding element, text** — and
text counts. Dropping to two is often stronger.

## Non-default legacy devices

Do not use these as routine house-style elements:

- Big red arrows or circles
- `FAIL`, `DANGER`, `BAD IDEA`, `WRONG` or comparable alarm copy
- Shocked-face cutouts
- Generic red glows, hazard stripes or explosion accents
- Large text that merely repeats the title
- Multiple unrelated objects competing for attention

A directional marker is allowed only when the relationship genuinely cannot be read without one. It must function as diagram notation, not as an excitement substitute.

## Canonical scenario layouts

### A - Visual paradox

One specific, surprising relationship with no text. The image should produce a question before it supplies an answer.

Example: a diesel nozzle apparently feeding the wrong internal part of a gasoline engine, or two incompatible objects joined with impossible confidence.

**Purpose:** Tests whether the scenario itself creates curiosity.

### B - Controlled comparison

A split, sequence or paired composition showing two states. If labels are needed, use neutral factual language such as `BEFORE / AFTER`, `PETROL / DIESEL` or `PUMP / ENGINE`.

**Purpose:** Tests whether immediate conceptual clarity outperforms mystery.

### C - Editorial tableau

Everyman participates in a specific visual situation with one restrained, deadpan incongruity. No generic reaction pose and no alarm copy.

Example: Everyman calmly consulting an owner's manual while the engine diagram behind him rearranges itself into an expensive problem.

**Purpose:** Tests whether the channel's character and comic point of view improve human interest.

## Compression-layout exception

For an “every type” or categorical episode, replace the scenario trio with a graphic inventory test: a small set of bold, differentiated icons or objects arranged as a clean visual system. Do not force a scenic tableau onto a topic whose real promise is classification.

## Testing protocol

For the first six episodes:

1. Hold the title constant and test thumbnail variants only.
2. Upload A, B and C through YouTube Studio's native A/B testing when eligible.
3. Make the concepts materially different; do not test minor color or wording changes.
4. Preserve variant A as the default when a test is inconclusive.
5. Record watch-time-share result, impressions, traffic mix and any declared winner.
6. Do not declare a universal house winner from one episode. Review patterns after six tests.

YouTube's native test optimizes for watch-time share, not click-through rate alone. A thumbnail that earns empty clicks is not a useful winner.

## Production template

Each episode's packaging brief must contain:

- Scenario in seven words or fewer
- Single surprising relationship
- A-layout visual paradox
- B-layout comparison and any neutral labels
- C-layout editorial tableau and dry visual joke
- Mobile-size legibility check
- Final title paired with all variants

The thumbnail package is part of the one-day episode workflow, not an afterthought after rendering.
