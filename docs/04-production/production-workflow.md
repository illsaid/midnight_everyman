# Production workflow

## Phase 1 - Topic and promise

1. Select a subject with broad human-interest tension.
2. Define the title/thumbnail promise before research expands.
3. Reject subjects that are merely complete, technical or enthusiast-friendly without a general-audience stake.

## Phase 2 - Script

1. Write for spoken clarity and visual opportunities.
2. Record or generate the final voice-over early.
3. Mark semantic beats and emphasis points.
4. Divide the narration into visual beats, normally three to five seconds each.

## Phase 3 - Visual planning

1. Assign one dominant visual action to each beat.
2. Reuse existing characters, poses, props, backgrounds and action patterns first.
3. Assign each Observer beat to a held cel or short cel sequence.
4. Create scene cards.
5. Create contact sheets for novel or complex motion.
6. List only the missing assets.

## Phase 4 - Asset creation

1. Generate related character poses together on one master sheet.
2. Add only the missing key poses justified by the beat plan.
3. Generate or select props and environments from the canonical SVG library.
4. Select approved drawings.
5. Remove chroma once and save normalized production assets.
6. Record anchor, scale, facing and semantic metadata.

Generated character video is outside the routine path. If used exceptionally, normalize the approved clip once and record its timing and entry/exit metadata.

Stock candidates enter through `assets-source/`. Only approved SVG/metadata pairs in `assets-canon/` may be used during assembly.

## Phase 5 - Assembly

1. Add the final voice-over.
2. Build scenes from reusable patterns.
3. Place character cels and props using anchor points.
4. Time pose changes to narration.
6. Add typography and diagrams.
7. Add restrained texture and transitions.

## Phase 6 - Review

1. Render contact frames from each beat.
2. Fix identity, silhouette, registration and framing problems.
3. Render the full sequence.
4. Review once without sound for visual clarity.
5. Review once audio-first for pacing and comprehension.
6. Record new reusable patterns and lessons.

## Phase 7 - Library update

After approval:

- Promote successful assets into the canonical library.
- Promote repeated timing into a named action pattern.
- Promote an exceptional performance plate only after cross-scene reuse is demonstrated.
- Update the character bible only when the change is intentional.
- Record experiment results and actual production time.

## Intended steady-state time budget

This is a target to test, not a proven estimate:

| Work | Target |
|---|---:|
| Topic, research and outline | 2.0 h |
| Script and voice-over | 1.5 h |
| Visual planning | 1.0 h |
| Missing asset generation | 1.0 h |
| Remotion assembly | 1.5 h |
| QA, render and upload package | 1.0 h |
| Total | 8.0 h |

The system fails commercially if routine episodes require extensive bespoke character drawing or shot-by-shot code repair.
